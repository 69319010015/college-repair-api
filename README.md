# ระบบแจ้งซ่อมคอมพิวเตอร์และอุปกรณ์ของวิทยาลัย - Back-End API

## ภาษาไทย

Back-End API สำหรับระบบแจ้งซ่อมคอมพิวเตอร์และอุปกรณ์ของวิทยาลัย
รองรับการแจ้งซ่อม การติดตามสถานะงานซ่อม และการจัดการข้อมูลอุปกรณ์ของผู้ใช้งาน

### โครงสร้างโปรเจกต์

```
.
├── src/            # ซอร์สโค้ดหลักของ API
│   └── index.js    # จุดเริ่มต้นของเซิร์ฟเวอร์
├── docs/           # เอกสารประกอบโปรเจกต์
│   └── uml/        # ไดอะแกรม UML (.png, .drawio)
├── .gitignore
├── package.json
└── README.md
```

### การเริ่มต้นใช้งาน

```bash
npm install
node src/index.js
```

## English

Back-End API for the College Computer Repair and Equipment Service System.
It supports repair requests, repair status tracking, and device/user data management.

### Project structure

```
.
├── src/            # main API source code
│   └── index.js    # server entry point
├── docs/           # project documentation
│   └── uml/        # UML diagrams (.png, .drawio)
├── .gitignore
├── package.json
└── README.md
```

### Getting started

```bash
npm install
node src/index.js
```
